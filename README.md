## Install and run

The recorded experiment uses Python 3.13, NumPy 2.5.3 and PyTorch 2.14.0. From the repository root on macOS/Linux:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python source/prototype.py
```

If the environment is already installed, only the last command is needed. On Windows, use `.venv\Scripts\python.exe` instead of `.venv/bin/python`.

The script prints a JSON summary and rewrites `source/crps.csv`, `source/attack_results.csv` and `source/results.json`. Those are synthetic results generated by the current run. The `.venv` directory stays local and is ignored by Git.

## What PyTorch does

NumPy simulates the PUF and generates the same 16,000 challenges and responses as before. PyTorch trains and evaluates the attacker:

- `nn.Linear`: one learned score per challenge; the existing constant feature supplies the intercept.
- `nn.BCEWithLogitsLoss`: compares predicted scores with known response bits using binary cross entropy.
- `loss.backward()`: calculates gradients automatically.
- `torch.optim.Adam`: updates the attacker coefficients for 500 full-batch steps.
- `torch.inference_mode()`: evaluates unseen challenges without training.

This is the same logistic-regression algorithm, now implemented with PyTorch. It has no hidden layers. Learning rate (0.05), L2 penalty (0.0001, excluding the intercept), zero initialization, dataset splits and training sizes (1k/5k/10k) are preserved. CPU float64 execution with one thread supports reproducibility; small numerical differences across platforms or library versions are possible. Training time includes model setup and may vary, especially on the first run.

## Scope

The prototype simulates a 64-stage Arbiter PUF and a three-chain XOR comparison. All results are synthetic. The full hybrid, Ring-Oscillator module and AI reliability controller are future work. A board-specific FPGA reference design is now included; physical implementation and qualification remain pending. Low accuracy from one simple attack is not proof of security.
